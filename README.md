# Open Source Free Realms - Linux Installer

A Linux installer and compatibility setup for Open Source Free Realms using Steam Proton.

## Requirements

- Linux
- x86_64 / AMD64 processor
- Steam
- Steam Proton

Proton Experimental is recommended.

## Features

- Detects Linux and CPU architecture
- Detects Steam and Proton
- Builds the patched Linux OSFR Launcher
- Creates a dedicated Proton environment
- Configures Free Realms for Linux
- Creates desktop integration
- Provides GUI installation and complete uninstallation

## Project Structure

- installer.py - graphical installer
- install.sh - installation backend
- OSFR-Launcher/ - modified OSFR Launcher source

## Status

Early development and testing.

Currently tested on Linux Mint.
